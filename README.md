# Boybi Aulia Putra — Portfolio Website

A responsive minimalist portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — layout, typography, responsive styles, and animations
- `script.js` — mobile navigation, scroll reveal, and reading progress

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real professional email address.
2. Add your real GitHub, LinkedIn, and other contact links when available.
3. Add screenshots, demo links, and source code for independent portfolio projects after you have built them.
4. Review all dates, role titles, and skill levels for accuracy.
5. Do not present the experience highlights under Projects as independent client projects. They are explicitly labeled as work experience.

## Publish
You can publish this static site using GitHub Pages, Netlify, or another static hosting provider. Upload all three website files while preserving their filenames and folder structure.
